# Règles de rédaction

## Pas de tirets cadratins

Ne jamais utiliser le tiret cadratin (`—`) ni le tiret demi-cadratin (`–`) comme
ponctuation, que ce soit dans le contenu du site, les commentaires de code, les
messages de commit ou les réponses dans le chat.

À la place, selon le sens :

- deux-points, pour annoncer ou expliquer ;
- parenthèses, pour une incise ;
- virgule, pour une pause simple ;
- point, en coupant la phrase en deux.

```
Mauvais : L'AESBT accompagne sa communauté — de l'arrivée à la réussite.
Bon     : L'AESBT accompagne sa communauté, de l'arrivée à la réussite.
Bon     : L'AESBT accompagne sa communauté : de l'arrivée à la réussite.
```

Le trait d'union reste normal dans les mots composés (« week-end », « au-delà »),
et le tiret reste autorisé dans les plages de dates ou de lieux quand aucune
autre forme ne convient (« Tunis - Ouagadougou »).
